Four Memory Types

From hard facts to emotional context — capturing everything.

Facts

📋 Facts

Concrete information: names, dates, numbers, code snippets, and verifiable data.

Preferences

⚙️ Preferences

User choices, opinions, workflows, and personalized settings.

Summaries

📝 Summaries

Compressed session overviews and key takeaways from past conversations.

Emotional

💭 Emotional

Sentiment, frustration markers, excitement, and relationship context.
